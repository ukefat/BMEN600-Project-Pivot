# Causal forecasting and masked reconstruction for temporal SSL

Final BMEN 600 research project. **Research question:** how do causal waveform forecasting and bidirectional masked waveform reconstruction affect the information accessible in learned time-series representations, and does this translate to EEG dementia classification?

We compare small Transformer encoders using similar architectures and matched training-update budgets. Three synthetic systems provide known generative factors; resting-state EEG provides a biomedical application. Waveform error, frozen representation content and diagnostic performance are evaluated separately.

## Project Evolution

The [original course project](https://github.com/Pouya-Ta/BMEN-600-Course-Project) focused on evaluating pretrained EEG foundation-model representations for dementia classification. We refined that scope to compare specific self-supervised learning (SSL) objectives under more controlled, computationally feasible conditions. Existing foundation models can differ simultaneously in architecture, training data, capacity, objectives and computational budget, making broad comparisons difficult to interpret. Similar small architectures and matched update budgets support a narrower, more rigorous investigation of causal forecasting versus bidirectional masked reconstruction.

The biomedical motivation remains EEG-based dementia classification. Synthetic dynamical systems and EEG spectral accessibility probes help explain what the representations capture before assessing diagnostic utility. Differences in prediction targets, available temporal information and task geometry remain; the final study **does not isolate attention direction alone**. The original repository provides historical context and remains separate. **This repository is the authoritative repository for the final submitted research paper**, including its analysis code, numerical evidence and figures; no migration of the original project's results is required.

## Final study and main findings

| Component | Design and evidence |
|---|---|
| Synthetic study | Three systems × two objectives, plus two task variants; 24 runs over three paired seed sets; [results and interpretation](reports/synthetic_summary.md) |
| Primary EEG comparison | Nine masked tasks (50/100/200 ms spans × 25/50/75%) and three causal tasks (4→4 s, 5.35→2.65 s, 6→2 s), three seeds each; [central results](reports/eeg_reconstruction_extended.md) |
| Representation checks | Matched untrained encoders, handcrafted spectral features, [pooling ablation](reports/eeg_pooling.md) and [window-level spectral probes](reports/eeg_window_spectral.md) |
| Supplement | [Paired uncertainty, FTD error destinations and verified QC](reports/eeg_supplement.md) |

- Synthetic pretraining improves recovery of selected temporal parameters, while many high local-state scores already exist before training. Longer prediction trades off recovery across factors.
- Primary mean-pooled EEG diagnosis averages **30.4–45.0% balanced accuracy** across pretrained configurations; handcrafted spectral features achieve **66.0%**. All 12 pretrained-minus-untrained participant-bootstrap intervals include zero.
- The seed-600 masked 50 ms/25% encoder has partial five-band spectral accessibility: average test R² **0.251 with mean+std**, versus **0.092 untrained**. This is not diagnosis accuracy and does not establish clinical utility.
- Reconstruction gains, spectral accessibility and diagnostic usefulness are distinct. More masking or longer prediction does not consistently improve all outcomes.

## Data and access

EEG: [OpenNeuro ds004504, version 1.0.9](https://openneuro.org/datasets/ds004504/versions/1.0.9), [dataset DOI](https://doi.org/10.18112/openneuro.ds004504.v1.0.9). The dataset declares **CC0** in its [versioned metadata](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004504/1.0.9/dataset_description.json). Cite Miltiadous et al., *Data* 8(6), 95 (2023), [data descriptor](https://doi.org/10.3390/data8060095); the metadata also requests acknowledgment of [DICE-net](https://doi.org/10.1109/ACCESS.2023.3294618) and the [AHEPA benchmark](https://doi.org/10.1007/s11571-026-10464-w).

There are 88 participants (36 AD, 23 FTD, 29 healthy controls), 19 channels at 500 Hz. We use supplied cleaned derivatives, preserve their reference/amplitudes, respect recording boundaries and form eight-second windows. The fixed participant split is 52/18/18; full SSL training uses 4,894 windows from the 52 training participants. Diagnosis uses identical first-four-second observations from 24 selected windows per participant. [Exact split](reports/submission_assets/participant_split.csv); [QC details](reports/eeg_supplement.md).

The datasets, full caches and checkpoints are **not in Git**. Synthetic trajectories are generated by [data.py](temporal_ssl/data.py). The [reproduction guide](docs/reproduction.md) provides the pinned EEG downloader and preparation commands. Public participant IDs, numerical results and a small attributed signal extract for the overview figure are included; they are not a replacement for downloading the dataset.

## Quick reproduction on CPU

From the repository root, using Python **3.12** (tested 3.12.3), on Linux:

```bash
python3.12 -m venv .venv-report
source .venv-report/bin/activate
python -m pip install -r requirements-report.txt
OPENBLAS_NUM_THREADS=1 python scripts/reproduce_submission.py
```

This reads **committed numerical results only**: no dataset, checkpoints, PyTorch, training or tuning. It creates `results/submission_preview/` containing cohort/QC tables, diagnostic and waveform summaries, spectral plots, paired intervals, FTD counts and synthetic trade-off/control figures. It verifies saved numerical agreement and writes `verification.json`. It refuses an existing output directory; use `--output results/submission_preview_repeat` for another run.

Optional: install the **Inkscape command-line executable** and add `--overview` to regenerate the editable overview SVG and 600-dpi PNG from the archived actual signal extract. The quick path took approximately **2.6 s on the study workstation**, including the overview; this is not a training-time estimate. See [the complete paper-output map and full reproduction steps](docs/reproduction.md).

## Full analysis environment and limitations

Full EEG analysis uses NumPy, SciPy, pandas, scikit-learn, joblib, requests, Matplotlib and PyTorch; tests use pytest. Install the recorded non-Torch packages with `python -m pip install -r requirements-analysis.txt` and the project with `python -m pip install -e '.[eeg,test]'`, after installing the appropriate PyTorch wheel. The recorded GPU environment is Python 3.12.3 / PyTorch 2.11.0+cu128 on an RTX 3090; exact observed versions and installation instructions are in [the reproduction guide](docs/reproduction.md#environment). Full EEG training modules explicitly use CUDA. No full training is needed to grade the saved results.

The test cohort is small (18 people, only five FTD), reused across exploratory analyses, and not an independent clinical validation. Seed SDs and participant-bootstrap intervals quantify different uncertainties. EEG model causality refers to supplied offline-cleaned signals. Targets, temporal access and prediction difficulty differ between objectives; matched updates do not imply matched computation. See the scientific reports for scope-specific limitations.

AI assistance was used for implementation, figures, documentation and analysis support. Recorded checks include paired controls, participant-disjoint splits, train-only scaling, leakage/access tests and saved-output audits. [Verification and outstanding checks](docs/SUBMISSION.md) distinguish executed checks from untested full reproduction; assistance does not replace author review of the submitted paper.

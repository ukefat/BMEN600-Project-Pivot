# EEG factorial study: fixed protocol

This protocol is fixed before downstream test evaluation. It tests capped versus full training-window coverage crossed with 25% versus 50% masking, using three paired seeds (600, 601, 602). The four conditions each receive 10,000 updates with batch size 64, for 640,000 draws per model. All draws select training participants uniformly and then windows uniformly within participant. Coverage counts must confirm every allowed window was visited.

The existing split is retained: 52 training, 18 validation, 18 test participants. Full conditions use all 4,894 usable non-overlapping eight-second training windows. Capped conditions use the exact original 1,248-window subset. Source-recording hashes, discontinuity handling, native montage/sampling, physical amplitude and QC remain unchanged. Cache preparation is deterministic and participant-local; it can prepare held-out recordings but never estimates population transformations from them. Training and model selection use only training/validation participants. Test EEG is supplied to models only after all 12 runs finish.

The architecture remains the original 32-dimensional, two-layer Transformer with a linear reconstruction head, 25-sample patches, four attention heads, no dropout, and masked-value/key exclusion. Mask spans are one patch (50 ms); exact-count uniform patch subsets hide 40 or 80 of 160 patches, and adjacent masks can merge. Fast vectorized uniform-subset masking replaces the slow sequential implementation with the same mask distribution. Realizations therefore differ from historical experiments. Both ratios are scored at final reconstruction evaluation using common per-ratio masks and interpolation/mean baselines.

AdamW uses learning rate 0.001, 500-update linear warmup, cosine decay to 0.00001, weight decay 0.01 and gradient clipping at 1.0. These are shared optimization changes, not swept settings. Model/sampling seeds are paired across conditions. Normalization remains the original capped-training-only per-channel scaling for all four conditions, preserving a common scale and avoiding implicit access to full-window statistics in capped conditions. Hidden-target loss is unchanged. Validation reconstruction on the same 432 windows is measured every 500 updates with fixed masks; the minimum among trained checkpoints selects the final model. Initialization is reported as a separate control. Resume checkpoints preserve optimizer, sampling/masking and Torch/CUDA RNG states.

Downstream classification and spectral probes use exactly the same original 24-window panels for every condition, so this tests pretraining data rather than a change in downstream averaging. All observe the first four seconds without masks. Mean patch embeddings are averaged within participant. Logistic regression settings remain fixed. The 152 original Welch spectral targets and validation-selected ridge grid remain unchanged. All scalers fit training participants only. Report seedwise scores, paired data/mask contrasts and their interaction, plus common-mask reconstruction. Retain negative spectral R². The handcrafted spectral classifier and untrained controls are references.

There are no adaptive budget extensions, nonlinear probes, architecture sweeps or test-based choices. Original course files and previous study artifacts are preserved. Three seeds measure initialization/sampling variability conditional on this split; 18 reused test participants and prior experimentation prevent treating this as independent confirmation. More windows do not increase the number of independent participants. Reconstruction-based checkpoint selection may not optimize diagnosis or spectral recovery.

Run: `CUBLAS_WORKSPACE_CONFIG=:4096:8 OPENBLAS_NUM_THREADS=1 .venv-gpu/bin/python -m temporal_ssl.eeg_factorial --config configs/eeg_factorial.json`.
